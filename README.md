# EdgeJump

**EdgeJump** is a client-side Minecraft mod designed to assist players with platforming and parkour by automatically executing a jump at the very last moment before falling off a block edge.

## 🏃‍♂️ Features

- **Perfect Auto-Jumps**: Never miss a jump again! Automatically jumps from the very edge of blocks as you walk or run.
- **In-Game Toggle**: Press **G** (default key) to easily toggle the mod on/off with an instant, clean, color-coded chat/HUD notification (`Auto Jump: ENABLED` / `Auto Jump: DISABLED`).
- **Edge Detection Sensitivity**: Fully adjustable sensitivity slider (from 1 to 20 ticks) to fine-tune how close to the block edge you must be to trigger the jump.
- **Mod Menu & Cloth Config**: Complete graphical settings screen integrated directly into Mod Menu.
- **Client-Side Only**: Works perfectly on any multiplayer server as well as singleplayer worlds without requiring any server-side installations.
- **Smart Safeguards**: Automatically disables jumping while sneaking (shifting), climbing ladders, gliding on Elytra, flying, or swimming in water/lava.

## ⚙️ Configuration

You can easily adjust the settings in-game:
1. Open **Mod Menu** in Minecraft settings.
2. Select **EdgeJump** and click **Settings**.
3. Toggle the mod or adjust the slider!

Settings are stored in `config/edgejump.json` inside your Minecraft folder.

## ⌨️ Default Keybinds

- **G**: Toggle EdgeJump (Auto-Jump). Can be bound to any other key in the standard Minecraft Controls menu.

## 📦 Requirements

- Fabric Loader
- Fabric API
- Mod Menu (Optional, to access settings menu)
